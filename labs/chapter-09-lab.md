# Chapter 9 Lab: Lakehouse Monitoring: Detecting Data and Model Drift

**Estimated time:** 25 minutes

## Exercise

Create a Lakehouse Monitoring inference-table monitor on a batch inference table, review the auto-generated profile and drift metrics tables, and identify which columns trigger a KS-test vs chi-square alert

## Key takeaway

Match the drift test to the data type — KS for continuous features, chi-square for categorical — this pairing is a top exam trap.
