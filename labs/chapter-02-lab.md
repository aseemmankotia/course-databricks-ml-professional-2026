# Chapter 2 Lab: Scaling and Hyperparameter Tuning: pandas Function API, Optuna, and Ray

**Estimated time:** 25 minutes

## Exercise

Use the pandas Function API to train one model per store/region in parallel, run an Optuna study to tune a single model's hyperparameters, and compare with a Ray Tune distributed search

## Key takeaway

Match the tool to the shape of the workload: pandas Function API for independent groups, Optuna for single-node search, Ray for cluster-distributed tuning.
