# Chapter 8 Lab: Testing ML Pipelines: Unit and Integration Tests for Production ML

**Estimated time:** 20 minutes

## Exercise

Write pytest unit tests for a feature-engineering function and a custom PyFunc predict method, then run an integration test that executes the full training pipeline on a small sample dataset inside a Databricks Job

## Key takeaway

Production ML pipelines need both unit tests on individual functions and integration tests on the full pipeline before promotion gates pass.
