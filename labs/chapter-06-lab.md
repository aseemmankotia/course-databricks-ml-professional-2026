# Chapter 6 Lab: Model Lifecycle Management: MLflow Model Registry and Models in Unity Catalog

**Estimated time:** 20 minutes

## Exercise

Register a trained model to a three-level Unity Catalog namespace, set a Champion alias, promote a new version to Challenger, and use the alias to load the model for scoring

## Key takeaway

Models in Unity Catalog with Champion/Challenger aliases are the current production standard, replacing legacy stage-based promotion.
